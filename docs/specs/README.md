règles. **Ils décrivent l'intention de départ** : le code et [ARCHITECTURE.md](../ARCHITECTURE.md) font foi sur le
fonctionnement réel (certaines valeurs ont changé depuis, par exemple la cible de protéines à 1,8 g/kg par défaut).
